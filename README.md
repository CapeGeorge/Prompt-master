# Prompt Master

Rewrites your rough prompt into a clear, complete prompt before you send it. Click the Prompt Master button in the band above the prompt box, or type /pm. The mod reads your draft, sends it to a Sonnet model with rewrite rules, and puts the better version back in the box. You review it and press Enter. An Undo button restores your original text. Run /pm followed by text to rewrite that text instead of the draft.

## Install

At the prompt of a terminal session:

```
/plugin install prompt-master --marketplace CapeGeorge/prompt-master
```

From a shell:

```
claude plugin install prompt-master --marketplace CapeGeorge/prompt-master
```
